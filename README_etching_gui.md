# X42 + Keithley 2400 钨丝刻蚀 GUI（初版）

运行文件：`etching_gui.py`

在 Anaconda Prompt 或 PowerShell 中执行：

```powershell
cd "C:\Users\yuze wu\Desktop\QTF\电化学法刻蚀钨丝_SPM_Q PLUS针尖\code"
py -3 .\etching_gui.py
```

依赖：`PyQt5`、`pyvisa`、`pyserial`、`matplotlib`。K2400 使用 VISA 地址（默认
`GPIB0::24::INSTR`），电机默认串口为 `COM5`、115200 baud。实际连接前请先确认
NI-VISA/对应 GPIB 驱动和电机 USB 串口驱动已经安装。

## 使用顺序

1. 在“设备连接”区域扫描/选择电机串口，点击“打开串口”。扫描/填写 K2400 VISA 地址后点击“连接 K2400”。
2. 连接会执行 `*IDN?` 验证真实仪器身份，并关闭输出；连接成功后默认不读取电流。电流限值 (Compliance) 会载入仪器原有值。
3. 在“Keithley 2400 手动控制”中设定电压、电流限值和电流量程，点击“应用电压/量程”。量程是测量档位，Compliance 是允许输出的电流上限，两者不同。K2400 允许的最高电流测量量程受 Compliance 所在档位及源电压档位限制；程序不会为切换量程而自动增大限流。
4. 点击“输出 ON”，再点“读取一次”只采集一个电流值。需要连续观察时，设置读取间隔，点“开始读取”；“停止读取”保留最后读数且不改变输出。点击“输出 OFF”同时停止手动采集。自动刻蚀结束后不会自动恢复手动采集。
5. 在“电机位置模式”中填写方向、速度、加速度和脉冲数，点击“发送指令”进行手动运动。
6. 在“自动刻蚀参数”中修改找液面、下探、监控和断点判定参数，选择保存文件夹及 CSV/参数 JSON/曲线 PNG。
7. 点击 `Start Etching`。程序会在后台线程执行找液面、下探、实时电流监控、断电和回撤；点击“停止”可以安全请求停止。自动刻蚀使用手动区的电流限值和量程，电压使用自动刻蚀区的“刻蚀电压”。自动流程中的电流采集是找液面和断点检测所必需的。

默认参数来自 `Auto_etching_code.py`。首次接入实际样品时建议先以较小电压、较短行程和较低监控时间验证电机方向、量程和电流单位。

## K2400 通信修复说明

原 GUI 每 500 ms 自动执行 `:MEAS:CURR?`。该命令隐式执行 `CONFigure`，会重置测量相关设置并打开输出，因此会覆盖手动量程，也可能在手动 OFF 后重新打开输出。GUI 现在显式初始化电压源、测量电流、单次内部触发、ASCII 电流格式，并用 `:READ?` 采集；输出关闭时拒绝读取。未使用 `*RST` 清空全部仪器配置。

连接使用 3 秒 VISA 超时、LF 读写结束符，并对 GPIB 请求远程控制。若使用 ASRL/RS-232，必须核对仪器面板的波特率、数据位、校验、流控和结束符与 VISA 会话一致；本次修复主要针对默认 GPIB 连接，未新增串口通信参数界面。

电压、量程和 ON/OFF 现在检查 `:SYST:ERR?` 并回读设置，错误码和具体描述会显示在运行日志中。连接前仪器已有错误也会报告，错误队列读取后被消耗；修正原因后可重新连接。超时后停止手动采集；读取失败会尝试中止测量并关断输出。请断开后重新连接，避免迟到的响应影响后续查询。未收到仪器确认时，应查看面板上的实际输出状态。

本次修改针对 `etching_gui.py`；旧的 `Auto_etching_code.py` 和 `test_monitor.py` 独立脚本仍保留原有采集方式，请从 `run_etching_gui.bat` 或 `etching_gui.py` 启动新版 GUI。

命令行为依据：[Keithley 2400 官方用户手册](https://download.tek.com/manual/2400S-900-01_K-Sep2011_User.pdf)，第 17 章及第 18 章电流量程部分。

无需硬件的回归检查：在本目录执行 `python -m unittest test_k2400_gui -v`。模拟检查不能代替真实仪器联机验证。
